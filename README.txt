RECIPE BOOK MERN STARTER

This is a starter structure for learning and building the Recipe Book requirements.
Complete the TODO sections yourself, then test every operation.

FOLDER STRUCTURE
recipe-book/
  frontend/
  backend/

1) Install Node.js (LTS) and open this folder in VS Code.
2) Open a terminal in backend:
   npm install
   Copy .env.example to .env and add your own TEST MongoDB Atlas URI.
   npm run dev
3) Open a second terminal in frontend:
   npm install
   npm run dev
4) Open the local URL shown by Vite.
5) Complete and test Create, Read all/by ID, Update and Delete.
6) Push both folders to a GitHub repository.

IMPORTANT:
- .env is intentionally excluded from Git in this starter. Do not publish real passwords or production secrets.
- For submission, follow your evaluator's exact instructions about environment files. If a dummy URI is required, use a disposable test database and never use a personal/production credential.
- Frontend API base URL is set in frontend/.env.example.
